# Career

A career is nested by player, then by season/year:

```text
career/<player>/<year>/
```

The committed `PLAYER/YEAR` directory is the empty starting skeleton. When a real career begins, rename those two directories rather than creating a second competing skeleton.

The player profile lives one level above the seasons so identity and career-wide facts are not duplicated every year.

Inside each year, `00_Team` is AI/GM-owned team state. The numbered 01 through 09 folders are the player's season route.
