# Offseason

Window: development blocks around the player's actual offseason commitments; work can overlap free agency, Summer League and national-team duties when applicable.

Player-controlled development choices and relevant offseason events belong here.

`note.md` starts at `not_started`. That file is a state container, not proof that the phase occurred.
