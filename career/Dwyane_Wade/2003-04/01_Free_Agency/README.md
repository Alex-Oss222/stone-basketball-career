# Free Agency

Window: the season's verified negotiation and signing periods. These are distinct dates; read the applicable contract rules before opening a live decision.

Player-facing market interest, offers, negotiations, decisions and completed signings belong here.

`note.md` starts at `not_started`. That file is a state container, not proof that the phase occurred.

## Player decision pages

Use the [contract desk](../../../../docs/templates/player_milestones/contract_negotiation.md) for an actual offer, eligible extension or option deadline. Use the [free-agency board](../../../../docs/templates/player_milestones/free_agency.md) to compare verified market opportunities. A contract expiring does not automatically generate another contract.
