# Player milestone screen library

**Illustrative templates only.** These independent scenarios use an Example Player, fictional offers and either fictional clubs or labeled NBA club contexts. They are not Wade's future, live offers, completed training, or simulation decisions. No live player response is recorded.

[Open the interactive screen gallery](career_milestones_preview.html) · [Blank templates](../../templates/player_milestones/README.md) · [Career](../../../career/Dwyane_Wade/README.md) · [Statistical examples](../player_stats_preview.md)

Nine reusable experiences, each with a different job. Start with the gallery to explore the screens, then open a filled example or copy its blank template. GitHub shows HTML source; download the gallery file and open it in a browser for the interactive view. It runs offline with no setup.

| Preview | The moment | The decision you would see |
| --- | --- | --- |
| [Career calendar](career_calendar.md) | Multiple summer obligations overlap | See what needs your response, who acts next and which appointment can move |

Each preview contains the immediate event, detailed evidence, player actions, unresolved questions and the next checkpoint. Trade has a transition dossier; training has a session and review plan; free agency has a rights and relationship board; negotiation has versioned terms. Their layouts and actions differ because the player has different control in each moment.

The gallery adds UFA/RFA scenario selection, a market-value dossier with three production profiles, offer comparison, a salary/option counter builder, trade-state branches, training choices and an action notebook. Inputs and actions remain local. The [market profile baseline](../../player_market_profile.md) estimates first-year worth from dated veteran contract evidence while keeping legal salary limits and club spending routes separate. [Exported example data](player_market_profile.example.json) labels synthetic player production explicitly.

The sample training review includes invented practice data. Financial examples illustrate the interface and arithmetic; they do not certify a legal transaction. Contract expiry never creates a replacement deal automatically.
